# 参考画面の元データ

- 戦闘絵の原本: `assets/battle-playable/stage.webp` (`battle/playable.html` / ユーザー提供 `akatsuki_visual_battle_playable.html` から抽出)。
- 比較用テンプレート: `assets/battle-v9/stage.png` (`battle/effect-target-v9.html` から参照)。
- 今回の参考絵: `assets/battle-reference/stage.png`。上記原本から作った参考絵を画像編集し、背景を伊賀の山中に変更。味方を左から「あやめ・家康・半蔵」、敵を「忍び3人、左馬之助、その後方の雪姫」に配置しています。原本そのものではありません。個別キャラのスプライトには分離していません。
- あやめの巨大手裏剣「飛燕」: 既存の武器カード `assets/004_c60caa07d.png` の、中央の環と四枚の湾曲した刃・黒金の装飾をデザイン参照。
- 縮尺・配置の修正: 飛燕の直径を前版の約半分へ。左馬之助と雪姫は遠近に合う大きさに縮小。人物の頭身と縮尺をそろえ、味方（武器を含む）は中央より左、敵（武器を含む）は中央より右に収めています。参考画面の中央ガイド線は横幅の50%に表示します。
- 家康: 既存の `assets/011_bb37a6d74.webp` の顔、緑と金の装束をデザイン参照。
- 左馬之助・雪姫・忍びのデザイン参照: `assets/012_f81fdb814.webp`、`016_e2b459444.webp`、`006_39739c7e4.png`。
- 斬撃・雷撃: `battle/effect-target-v9.html` のCanvas実装を `battle-effects.js` に再利用。命中位置と表示ラベルを調整し、効果は被弾する側の半面内にクリップしています。ダメージ数値は表示しません。雷・粒子テクスチャは `assets/battle-v9/` の原物を参照します。
- 会話欄の顔画像: 既存 `assets/` の半蔵・あやめ・左馬之助・雪姫を参照。

会話5行は配置・演出確認用。本編の本文や戦闘接続は変更していません。

UIでは元のイラストを縦に移動して空と地面の余白を詰め、下部の会話欄・顔・文字を拡大しています。画像とCanvasエフェクトは同じ領域で移動するため、表示を上へ寄せても命中位置は一致します。イラスト自体や人物の左右配置・縮尺は変更していません。コマンドはHTML内のSVGアイコンと短い名称、読み上げ用の操作名を併用しています。

右の章情報パネルを削除し、6つの戦闘コマンド（斬撃・飛燕・忍術・守る・回復・連携）と会話送りを分けました。HP・MPは味方3人の表示確認用データで、本編の能力値ではありません。飛燕・忍術・連携のMP消費と、回復薬のHP・MP回復をプレビューできます。斬撃・雷撃の元処理に加え、元の粒子・光輪テクスチャで飛燕の風、守り、回復、連携を合成しています。攻撃は右半面、防御と回復は左半面で描画します。

名前の読みやすさを改善するため、味方名は濃い背景・白文字・水色枠のプレートに変更。敵名はゲージ右側の説明文を置き換えた赤い枠の専用欄へ移動しました。敵が話すときの横スクロールは、名札のUI位置ではなくイラスト上の位置を参照します。
