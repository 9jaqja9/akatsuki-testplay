# akatsuki-testplay

『暁ノ刃』の本文UIと、アップロードされた最新版の戦闘イベントを統合した確認版です。

## 横スクロール戦闘の参考画面

今回の配置確認は `reference/battle-reference.html` を開いてください。画像だけなら `reference/battle-reference.png` で確認できます。ZIPは全体を解凍し、`assets` フォルダーを含む構成を保ってください。

イラストを上段へ寄せ、下段の会話ウィンドウ・顔アイコン・台詞を大きくしています。操作は吹き出し（会話）、交差した刀（斬撃）、稲妻（雷撃）、回転矢印（最初に戻す）のアイコンです。短い名前も併記し、PCではカーソルを重ねると詳しい操作名が表示されます。

`battle/playable.html` の戦闘絵を元に、背景を伊賀の山中へ変更。味方は左からあやめ・家康・半蔵、敵は忍び3人 → 左馬之助 → 後方の雪姫という配置です。人物の縮尺を統一し、左馬之助と雪姫を縮小。飛燕の直径は前版の約半分にしています。中央のガイド線（横幅50%）を境に、味方と武器は左半分、敵と武器は右半分に収まる配置です。`battle/effect-target-v9.html` の斬撃処理と `assets/battle-v9/` の雷・粒子画像を再利用しています。「会話を進める」「斬り合いの演出」「雷撃の演出」「最初の配置に戻す」を試せます。「元の画面」でいただいたv9の原本を比較表示します。今回の参考画面は本編に接続していません。台詞は演出確認用です。

## 起動

GitHub の **Code → Download ZIP** で取得したZIPを解凍し、このREADMEがあるフォルダーを静的Webサーバーで配信してください。

Python 3 がある環境では、そのフォルダーで次を実行できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows で `python3` が使えない場合は、`py -3 -m http.server 8000 --bind 127.0.0.1` を実行します。ブラウザーのアドレス欄に `http://127.0.0.1:8000/index.html` を入力して開きます。

画像・音声・CSS・JavaScriptのフォルダー構成を保ってください。入口は `index.html` です。

## 操作と収録範囲

- タイトルの「スタート」で本文を開始します。文章送り・戻る・文字サイズ変更ができます。
- ノベルが主軸です。第一章の襲撃場面で、一度だけ短い戦闘演出が自動的に入ります。
- 第一章の目的は「家康を守り、道を開く」。半蔵・あやめ・家康の3場面を、一つずつボタンで進めます。
- 難しい戦略や勝敗のやり直しはありません。「操作せずに読む」でも同じ内容を読めます。
- 終了すると、家康の「無茶はするなよ」の場面へ戻ります。中断した場合は戦闘前の本文に戻ります。
- 同じプレイ中には一度だけ発生し、セーブ・再開でも完了状態を保ちます。「スタート」で新しく始めると再び体験できます。
- タイトルの「別場面の戦闘」は、以前いただいた信長との戦闘試作です。「演出テスト v9」はエフェクト位置確認用の別デモです。

本文は元のリポジトリにある第一章までです。第二章以降の目的と自動挿入位置は、その章の本文に合わせて設定します。第17章の本文への自動接続は未実装です。

PC・スマホ縦横で、第一章の戦闘の開始・完了・本文復帰・中断・完了後の再読・セーブと再開・新規開始・読むだけの経路を確認しています。

戦闘の方針は [battle/STORY_DESIGN.md](battle/STORY_DESIGN.md)、各ファイルの説明は [battle/README.md](battle/README.md) を参照してください。
