# akatsuki-testplay

『暁ノ刃』の本文UIと、アップロードされた最新版の戦闘イベントを統合した確認版です。

## 起動

GitHub の **Code → Download ZIP** で取得したZIPを解凍し、このREADMEがあるフォルダーを静的Webサーバーで配信してください。

Python 3 がある環境では、そのフォルダーで次を実行できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows で `python3` が使えない場合は、`py -3 -m http.server 8000 --bind 127.0.0.1` を実行します。ブラウザーのアドレス欄に `http://127.0.0.1:8000/index.html` を入力して開きます。

画像・音声・CSS・JavaScriptのフォルダー構成を保ってください。入口は `index.html` です。

## 操作と収録範囲

- タイトルの「スタート」で本文を開始します。文章送り・戻る・文字サイズ変更ができます。
- タイトルの「戦闘をプレイ」、または本文下部の剣ボタンで最新版の戦闘イベントを開きます。
- 4つのコマンドを8回選ぶと、魂の境目を発見するイベントが完了します。
- 「物語に戻る」で読みかけの位置へ戻り、「もう一度プレイ」で再戦できます。戦闘中の「戻る」または Escape は中断です。
- 「演出テスト v9」は、以前のエフェクト位置確認用デモです。

本文は元のリポジトリにある第一章までです。後の章の戦闘は別場面として手動で開く構成で、第17章での自動開始や、その後の分岐は未実装です。信長のHPや通常の勝敗判定は、提供された戦闘には含まれていません。

PC・スマホ縦横で、本文の基本操作、戦闘の8回行動による完了、本文への復帰、中断を確認済みです。再戦はPCで確認しています。詳細は [battle/README.md](battle/README.md) を参照してください。
