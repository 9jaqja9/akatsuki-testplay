# 暁ノ刃：戦闘と本文の接続

## プレイできる最新版

ユーザー提供の `akatsuki_visual_battle_playable.html` を `playable.html` として取り込んでいます。元の背景画像は変更せず、埋め込み画像を `assets/battle-playable/stage.webp` に抽出しています。4つのコマンド、会話、8回行動で魂の境目を見つける進行は提供版に沿っています。

- タイトルの「戦闘をプレイ」から開始できます。終了画面の「物語に戻る」で、保存された本文の位置を開きます。
- 本文の下部にある剣のボタンからも開始できます。終了または中断後は、読んでいた位置・表示中の文章に戻ります。
- 戦闘中の「戻る」または Escape で中断できます。中断によって本文の進行位置が変わることはありません。
- 終了画面の「もう一度プレイ」で再戦できます。提供版では行動時にすべてのボタンを無効にするため再戦ボタンが使えなくなっていました。行動ボタンだけを無効にするよう修正しています。
- 初回の進捗表示を0%に揃え、再戦時は前の進行タイマーを解除します。
- 信長のHP・通常の勝敗判定は提供版にありません。終了条件は魂の境目を発見するイベントです。
- 現在の本文は第一章までです。この後の戦闘を誤った章へ自動挿入せず、手動で別場面を開く構成です。第17章の本文・分岐条件が揃ったら、その場面で自動開始する処理を追加できます。

戦闘画面はsandbox付きiframeで開きます。本文とスタイル・変数を分離し、戻るときにフレームを破棄して戦闘のタイマーを停止します。

## 以前の演出テスト v9

`akatsuki_effect_target_demo_v9.zip` の内容は `effect-target-v9.html` に残してあります。タイトルの「演出テスト v9」から確認できます。

- `run()` 末尾の余分な `}` を修正しました。
- 埋め込み画像5点を元のバイト列のまま `assets/battle-v9/` に移しました。
- 雷撃・斬撃・黒炎・回復と命中座標を確認するデモです。プレイできる最新版の戦闘とは分けています。
- 元デモの背景にあるAUTO・LOG・CONFIGなどは画像の一部です。Effekseer形式を直接再生する実装ではありません。

## 起動と検証

リポジトリ直下で `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、そのサーバーの `index.html` を開きます。

ローカル検証スクリプトは `/workspace/setup-checks/` にあります。

- `playable-battle.cjs`: PC・スマホ縦・スマホ横で4コマンド、8回行動の完了、本文への復帰、中断、PCでの再戦を検証します。
- `reader-ui.cjs`: 3つの表示で文章送り・戻る・文字サイズ・章題・人物画像・会話を検証します。
- `battle-v9.cjs`: 以前の演出テストを検証します。
